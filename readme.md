 📝 To-Do Manager – JavaScript + WordPress CMS Integration

A responsive and feature-rich To-Do List application built with HTML, CSS, Bootstrap, and JavaScript. This project demonstrates how custom frontend apps can be cleanly embedded and integrated into WordPress CMS environments — combining modern UI/UX with enterprise-grade content platforms.
---

 🔧 Features

- ✅ Add, edit, delete, and tasks
- 🌙 Dark mode toggle (pure CSS/JS)
- 📱 Fully responsive design using Bootstrap 5
- 🗃️ Stores tasks using `localStorage` for persistence
- 🌐 Embedded inside a WordPress page using the Gutenberg HTML block

---

---

 🧠 WordPress Integration

This project was embedded into a WordPress page using the **Gutenberg HTML block**:

1. Created a custom WordPress page
2. Pasted the HTML structure, inline styles, and JavaScript inside a `<script>` tag
3. Adjusted layout and verified responsiveness
4. Used WordPress only as a CMS container — no PHP or backend required

---

 🛠 Tech Stack

- HTML5, CSS3, Bootstrap 5
- JavaScript (ES6)
- WordPress CMS (self-hosted)
- Browser localStorage
